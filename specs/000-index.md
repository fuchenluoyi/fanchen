# 规范索引（Spec Index）

> 项目代号：`fanchen-desk`（凡尘·需求台）
> 交付物：一个网页版原型 —— 与 AI 角色对话，AI 话里出现"需求"时自动提取成任务，进入右侧任务清单。

## 1. 这套规范怎么用（SDD 工作流）

本项目采用 Spec-Driven Development：**先定规范 → 再定依赖 → 再拆任务 → 再逐条实现 → 最后按验收标准回验**。

```
001 愿景  ──▶ 002 需求(FR/NFR + 验收标准)
                    │
                    ▼
              003 架构(模块/数据/依赖)
                    │
                    ├──▶ 004 接口契约
                    └──▶ 007 决策记录(ADR)
                    │
                    ▼
              005 任务拆解(T1..T7 + DAG)
                    │
                    ▼
              006 测试计划  ──▶ 实现 ──▶ 回验
```

规则：
1. **任何需求都有编号**（`FR-xxx` / `NFR-xxx`），任何任务都声明它实现了哪些编号。
2. **验收标准先写死**，实现完成后逐条勾选，不允许"看起来能跑"就算完成。
3. 实现中若发现规范有误，**先改规范再改代码**，并在 `007-decisions.md` 记录原因。
