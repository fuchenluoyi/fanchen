# 001 愿景与范围

## 1. 背景

参考《不问凡尘》这类以对话驱动的游戏体验：玩家与 NPC 交谈，NPC 的话语中透露出"需求"，玩家把它接成"任务"，任务出现在侧边清单里并可持续推进。

把这种体验搬到网页上，但底层不是写死的剧本，而是**真实的 AI Agent**：
- 对话内容是模型实时生成的，不是预设分支；
- "需求 → 任务"这一步由 Agent 主动决策（函数调用）或由抽取管线补足，而不是人工整理。

## 2. 目标（Goals）

| # | 目标 | 可验证信号 |
| --- | --- | --- |
| G1 | 网页里能与 AI 连续对话，逐字流式输出 | 消息实时增长，可中断 |
| G2 | 页面内可接入任意 OpenAI 兼容服务（DeepSeek/OpenAI/Ollama/vLLM） | 改 baseURL+Key+模型名即可通话 |
| G3 | Agent 能在对话中**主动**把用户需求登记为任务 | 模型中调用 `create_task`，右侧立刻出现任务 |
| G4 | 即使模型不支持工具调用，也能从话里抽出需求 | 规则触发 + LLM 结构化抽取双保险 |
| G5 | 任务清单可管理：确认入列、状态流转、去重、持久化 | 刷新页面任务仍在 |
| G6 | 全过程可审计：每条任务能说清"从哪句话来、谁抽的、多可信" | 任务卡显示来源与原话 |

## 3. 非目标（Non-Goals）

明确不做，避免范围蔓延：

- ❌ 不做游戏引擎/剧情脚本系统（无分支剧情、无存档、无战斗）。
- ❌ 不做多用户、账号、权限、云端同步。
- ❌ 不做美术资源（立绘、背景、音效）—— 界面按用户要求用**矩形框**简洁呈现。
- ❌ 不做向量数据库/RAG 语义去重（用轻量字符串相似度）。
- ❌ 不把 API Key 存到服务端磁盘；不做服务端会话持久化。
- ❌ 不做移动端原生适配（仅响应式布局）。

## 4. 目标用户与核心场景

**用户**：产品/开发人员，用 AI 讨论想法，希望需求被自动记下来而不是散落在聊天记录里。

**主场景（Happy Path）**
1. 用户打开页面，填入 baseURL / API Key / 模型名，保存。
2. 用户说："我想做一个给团队用的值班排班工具，需要支持换班申请和自动提醒。"
3. AI 回复、并调用 `create_task` 登记两条任务（换班申请、自动提醒）。
4. 右侧任务清单出现两张**待确认任务卡**，用户点"采纳"，任务进入"待办"。
5. 用户继续聊，AI 又提到"最好还能导出成 Excel" → 抽取通道发现新需求 → 新任务卡。
6. 用户把"换班申请"标为"进行中"，刷新页面，状态仍在。

**边界场景**
- 模型不支持 function calling → 自动降级，靠抽取通道兜底。
- 用户没填 Key → 抽取降级为纯规则，任务仍能出现（标题质量下降，标注 `rule`）。
- 网络报错/额度不足 → 明确错误提示，不吞异常。

## 5. 约束

| 类型 | 约束 |
| --- | --- |
| 运行环境 | Windows + Node ≥ 20（本机 Node 24.21），pnpm 11.7 |
| 浏览器 | Chromium 系（SSE / fetch stream 支持） |
| 前端 | Vite + React + TypeScript |
| 后端 | Node 内置模块（零运行时依赖），仅做代理与静态托管 |
| 存储 | 浏览器 localStorage（设置、消息、任务） |
| 网络 | 需能访问所配置的模型服务；localhost 内通信 |

## 6. 术语表

| 术语 | 含义 |
| --- | --- |
| **对话区（Chat）** | 左侧/主区，用户与 AI 的多轮消息流 |
| **任务清单（Task Panel）** | 右侧面板，存放被提取出来的需求 |
| **需求（Requirement）** | AI（或用户）话语中表达的、可执行的期望/待办 |
| **任务（Task）** | 被结构化的需求：标题、详情、分类、优先级、验收要点、状态 |
| **候选（Candidate）** | 已抽取但尚未被用户采纳的任务草稿 |
| **工具通道（Tool Channel）** | 模型通过 function calling 主动登记任务 |
| **抽取通道（Extraction Channel）** | 回复结束后，由规则触发 + LLM 结构化抽取补足任务 |
| **规则引擎（Rule Engine）** | 纯函数关键词/模式打分器，判断一段话是否含需求，并可离线产出候选 |
| **角色（Persona）** | 系统提示词定义的 NPC 口吻 |
